其中
$$\begin{aligned} F_1 &= c/6 + 5\{d + (K_0 - K)\}/6 + w/3 + q_e/6 + w_o + B_c - 5g/6 + \ell, \\ F_2 &= 2b_2 - \frac{5}{6}g_2 - p_2 + t_2 + V/6 + f/6. \end{aligned} \tag{18.43}$$
实际超出量由式 (18.42) 中的名义表达式加上 $\delta_{\text{fr,2}}/6 + 2\theta_N + \epsilon_1$ 所界定。
为进行显式验证，式 (18.42) 的左端首先等于

$$a_0 - 2b_2 + p_2 - w - B_c - \ell - \frac{5}{6}m' - q' - f/6.$$

代入式 (18.32) 以及 $K = 2A - c - d + R + E - m - (K_0 - K)$，即得式 (18.42)–(18.43)。
下列下界正是完全公共支撑不耗尽可用指数的原因：
$$F_1 \ge \frac{2}{3}(c + w) - 3\sigma - \frac{5}{6}\delta_{\text{fr,1}}, \quad F_2 \ge \frac{2}{3}b_2. \tag{18.44}$$
为证明第一个不等式，令 $D_0 = d + K_0 - K$，初始取 $g = J^+$ 及 $\ell = 0$，并回忆 $J = D_0 - c - 2w + w_o$。当 $J \ge 0$ 时，直接化简得

$$F_1 = c + 2w + q_e/6 + w_o/6 + B_c \ge c + 2w.$$

当 $J < 0$ 时，利用 $q_e \ge R$ 及

$$B_c + q_e/6 \ge (3c - 5D_0)^+/6 - \frac{5}{6}\delta_{\text{fr,1}}.$$

事实上，左端至少为 $\{(3c - 5d - R)^+ + R\}/6$，而此式至少为 $(3c - 5d)^+/6$，同时 $D_0 \ge d - \delta_{\text{fr,1}}$。正部是 1-Lipschitz 的，故得所显示的修正。由此推出
$$F_1 \ge \frac{c + 5D_0 + (3c - 5D_0)^+}{6} + \frac{w}{3} - \frac{5}{6}\delta_{\text{fr,1}} \ge \frac{2}{3}(c + w) - \frac{w}{3} - \frac{5}{6}\delta_{\text{fr,1}}.$$
实际选取满足 $g \le J^+ + 2\sigma$ 及 $\ell \ge 0$。因此式 (18.29) 将来自 $2(c + w)/3$ 的额外损失界定为

$$w/3 + 5\sigma/3 + \frac{5}{6}\delta_{\text{fr,1}} \le 22\sigma/9 + \frac{5}{6}\delta_{\text{fr,1}} < 3\sigma + \frac{5}{6}\delta_{\text{fr,1}}.$$

对于式 (18.44) 中的第二个不等式，由 $F_2$ 的定义逐个素数计算。以素数的对数范数为单位，各贡献为
公共情形 $F_2 \quad b_2$
单位 $i = i,\, 6 \nmid i \quad 7i/6 \quad i$
非单位 $i = i,\, 6 \nmid i \quad (7i - 5)/6 + \frac{1}{3}1_{i = 1} \quad i$
任意 $i = i,\, 6 \mid i \quad 7i/6 - 1 \quad i$
单位 $i > j_0,\, 6 \mid j_0 \quad i + j_0/6 - 1 \quad (i + j_0)/2.$
第二行中额外的 $1/3$ 来自 $f/6$。第一行超过 $2b_2/3$。第二行在 $i = 1$ 时取等号，而对 $i \ge 2$，差为 $(3i - 5)/6 \ge 0$。第三行中差为 $(i - 2)/2 \ge 0$，因为 $i \ge 6$。最后一行中差为 $(4i - j_0 - 6)/6 \ge 0$，因为 $j_0 \ge 6$ 且 $i \ge j_0 + 1$。求和即证得该断言。
对于非中心范围 $A \le 5M/6$，式 (18.42)–(18.44) 将名义例外超出量界定为 $3\sigma + 5\delta_{\text{fr,1}}/6$。上面记录的实际计数修正与总体支撑修正是在固定阶段配额中进一步的 $O(\xi)$ 项。结合对角估计与较小宽度估计，这就在当前宽度下以所保留的终端损失证明了非中心阶段。因此，先前构造的比较可以使用该阶段。剩下的就是在 $A > 5M/6$ 时估计中心例外项。
