长度 d 使 $A_{\mathrm{act}} + (6\kappa - 1)z_{\mathrm{act}}$ 减少 $6\kappa d$，并对平方 $Z$-指数贡献 $\kappa d$，而固定半范数与高度因子分别保留。由于每个槽的长度至多为 $\eta$，将正活跃长度排序并取第一个达到 $F_{\mathrm{act}}/(6\kappa)$ 的前缀。其前一个前缀小于该阈值，且其最后一个槽的长度至多为 $\eta$。若没有前缀达到该阈值，则移除所有槽，其总和更小。因此恰有一个槽可能导致超出，且被移除的总长度 $d_z$ 满足
$$d_z \le \min\left\{z_{\mathrm{act}},\ \frac{F_{\mathrm{act}}}{6\kappa} + \eta\right\}, \tag{18.39}$$
$$\kappa d_z \le \frac{F_{\mathrm{act}}}{6} + \kappa\eta \le \Delta_{\mathrm{child}} + \frac{\delta_{\mathrm{fr},1}}{6} + \frac{\theta_N}{3} + \eta.$$
若这些槽在到达仿射边界之前消失，则剩余的普通长度可以是任意的；这正是完备的更小宽度零槽断言包含所有长度的原因。否则对剩余乘积应用正槽归纳法。其槽仍具有原来的系数类，且其诱导行仍位于 $\Theta$ 之外。Cauchy–Schwarz 对两个分别截断的子代的误差取平均，因此它们可能不同的矩形与槽集合不会使 $\eta$ 加倍。将式 (18.39) 与式 (18.37) 中的配对系数界以及 $M_{\mathrm{act}}' - M' \le \delta_{\mathrm{fr},2}$ 结合，超出子代包络的严格边尺度代价至多为
$$\delta_{\mathrm{fr},2} + \frac{\delta_{\mathrm{fr},1}}{6} + \eta + \frac{7\theta_N}{3}. \tag{18.40}$$
若无槽存活，则同样的界成立，且无需贪心代价。数值项 $\theta_N$ 与两个频率修正给出了在使用式 (18.33) 时从式 (18.25) 继承的 $\epsilon_G$ 储备中的单个 $O(\xi + \eta)$ 边损失；现有的局部小幂因子与固定解析因子保持分离。逐点估计对整个被移除乘积只请求一次；其内部的小幂份额可能依赖于 $N$。这一贪心操作仅在实际子代的所有边界缺陷都已被包含进 $F_{\mathrm{act}}$ 之后才发生。$d_2$ 一侧的论证相同，只需交换 $c_2$ 与 $d_2$。

我们现在已经用仅更小的宽度界定了所有诱导特征位于 $\Theta$ 之外的子代行。对于剩余的行，接下来的计数与体积界处理非中心范围；中心范围则使用系数引理中保留的减除。

18.7 诱导特征位于 $\Theta$ 中的行

在本小节中，当子代行的诱导特征属于 $\Theta$ 时，称该行为例外行。由系数引理，两个分离的侧要么都是例外行，要么都不是。现有完整显示的移动支撑中的每个素数都是公共列零，每个额外的公共穿孔亦然。这在初始时成立，在第一次变换中对 $e$、$r$ 保持成立，并且对放大器素数保持成立。对于非零的真正二次分配，因子 $\tau_1(D_2)$、$\tau_1(E_2)$ 与旧的公共掩码因此迫使其完全根式与所有这些支撑不相交。这一结论是在将任何冻结标量替换为上界之前得出的。人工剩余延拓保持 $D_2$、$E_2$ 及那些掩码固定，无法复活一个不可能的分配。
