令当 $Q_i=0$ 时 $g_i=0$，并且对来自方程 (16.9) 的误差槽也令 $g_i=0$。那么，对于一个主槽，

$$|Q_i| \le P_i g_i + \vartheta, \quad g_i > 0 \implies |Q_i| \ge P_i g_i.$$

对于 $g_i=0$ 的槽，不断言下界。有限多个可能的向量 $(g_i)$，连同可能的端点值 $\delta/2$，将各行划分为振幅箱。定义它们的长度加权平均为

$$q = \frac{\sum_i \ell_i g_i}{\ell}, \quad 0 \le q \le \delta/2, \quad \ell = \sum_i \ell_i. \tag{19.1}$$

这个 $q$ 记录了素振幅；它不是辅助第四矩中记作 $q$ 的导子指数。

19.2 选定的素槽与行计数

使用方程 (12.1) 中的 $\Delta$ 和 $\kappa$：

$$0 < \Delta \le \frac{1}{24}, \quad \kappa = 2\beta_{*}- 1 = \frac{3}{4} + 2\Delta \in (3/4, 5/6], \quad \alpha := \frac{5}{6}.$$

参数 $\kappa$ 保持动态；$\alpha$ 是来自六次幂放大的固定斜率。由于 $\kappa < 1$ 且 $\beta_{*}= (1+\kappa)/2$，引理 18.1 的正槽假设由等式满足。方程 (12.2) 给出当前第二部分各箱的 $\delta \le \kappa \le \alpha$，包括可能的端点 $\delta = \alpha$。

固定一个动态与振幅箱，并固定外部物理 Mellin 参数。记 $z_{\mathrm{phys}}$ 为固定的第三 Mellin 参数，于是物理槽为 $Q_i(u; z_{\mathrm{phys}})$。所有 $g_i$ 以及因此 $q$，现在都在其行和中固定。在基 $U$ 处，槽 $i$ 的长度为 $w_i = \ell_i/d$，总可用长度为 $\ell/d$。对于请求长度 $0 \le z \le \ell/d$，将正的 $g_i$ 按降序排列，并按该顺序以分数方式填充 $z$。获得的指数至少为 $qz$：若正槽足以填满 $z$，它们的初始加权平均至少为所有槽的平均值 $q$；否则保留它们全部给出增益 $q\ell/d \ge qz$。去掉那一个可能为分数的槽至多损失 $(\max_i w_i)\delta/2$。因此，长度至多为 $z$ 的整正槽的一个固定子集满足

$$\prod_{i \text{ selected}} |Q_i|^2 \ge U^{2qz - \delta \max_i w_i}.$$

当需要严格矩不等式时，我们首先将 $z$ 替换为 $z - \nu_0$，其中 $\nu_0 > 0$ 为固定小数，或者若 $z \le \nu_0$ 则不选任何槽。此式中由此产生的损失至多为 $2q\nu_0 + \delta \max_i w_i$，除了所述零容量邻域，在那里将使用未加权矩。两种损失都可以做到小于任何预先给定的正幂。

$$\overline{\nu(p)1_{p \in 1_T}} = \frac{1}{|T|} \sum_{\theta \in \widehat{T}} (\overline{\nu\theta})(p).$$
