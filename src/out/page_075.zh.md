沿坐标轴取形如式 (10.6) 的一个优函数，并在那里积分。迹估计使接合项趋于零。

在进一步移动 $s$ 之前，将三个原始 Mellin 高度限制到所述盒子中。在舍弃的部分上，令 $s$ 保持在 $\Re s = \beta_{*}+ 20e$。那里，全局倒数界、全局分子界、被删因子以及全高度修正界给出 $Z^{B_\eta}$ 乘以高度的某个固定多项式：行数范围由 $q_u \ll Z^{d_{\max}}$ 界定，而行数为 $O(U)$。引理 10.2 中的积分尾项给出 $O_{\eta,N}(Z^{B_\eta} T_1^{-N})$。

只将保留下来的 $s$ 段移动到 $a + 16e$。在这个矩形上，

$$\Re(s + w) \geq 1 + 10e,$$

而定义 $D_1(10e)$ 的其它不等式仍然成立。倒数宗量的实部至少为 $a + 16e > a + 6e$。所述高度盒子使两个标量宗量严格位于 $|\Im v| \leq (3i + 2)T_1$ 之内，只要 $Z$ 充分大。因此引理 8.1 在整个保留矩形上排除了它的零点。由于 $6z_0 > 1$，标量 zeta 因子在这次移动中没有极点。因此没有越过任何极点。

对于 $s$-接合项，其虚部坐标固定为 $T_1$ 的某个常数倍。式 (10.5) 中的标量分母只依赖于 $s$，因此当 $\Im z$ 和 $\Im w$ 的积分延拓到各自的整条坐标轴时，其缓冲估计仍然有效。在这些延拓后的坐标轴上使用全局分子估计和式 (10.4)。迹估计随即给出 $O_{\eta,N}(Z^{B_\eta} T_1^{-N})$。本论证中的任何 $w$- 或 $z$-接合项都不会延拓一条已被移动到仅处于缓冲区域的 $s$ 轴。

精确的高表示是一个三重积分，并带有一个控制其全部修正的优函数。因此我们可以在引入任何辅助分离变量之前进行这一变换。如果某个中心估计后来使用了这类变量，那么它们的保留区域和舍弃部分必须在该估计中得到论证；它们并不是刚刚证明的围道恒等式的新坐标。

10.5 应用行包络

对于基本修正，引理 7.1 验证了引理 10.3 的假设。事实上，在两个 Euler 区域中，$|H_{\eta,u}| \ll_\epsilon q_u^\epsilon$ 关于三个高度一致成立；对于 $q_u \leq Z^D$，取 $\epsilon = 1$ 即得式 (10.4)，其中 $B = D$ 且高度阶为零。我们现在估计保留的积分，在本小节中始终取 $l_x = l_y = h = 1/2$ 以及 $\ell = 0$。

固定

$$d_{\min} = \frac{1}{63}, \quad \zeta = \frac{1}{1000}, \quad d_{\max} = h + \zeta = \frac{501}{1000}.$$

对于该范围内形如 $U = Z^d$ 的二进区间，在移动任何 Mellin 变量之前固定一个动态箱 $(i, a)$，并令 $\delta = 2a - 1$。命题 9.2 以要求的损失 $\epsilon_r > 0$ 给出其基数至多为一个固定常数倍的 $U^{R(\delta)+\epsilon_r} (1 + T_1)^{A_\eta}$。对于底层箱，这就是直接计数 $O_\eta(U)$，因为 $R(1/50) = 1$；它不使用任何见证。

分子 $L_S(w, \chi_\bullet(u))$ 恰好就是第 8 节中 $\nu = 1$ 时的原始零延拓表示。在保留直线 $\Re w = 1 - a - 6e$ 上，引理 8.1 对任意 $\epsilon_n > 0$ 将其界定为 $U^{\delta/2 + 12e + \epsilon_n} (3 + T_1)^C$。这在底层箱中也成立。中心点位于 $D_1(10e)$ 中，因此引理 7.1 中更强的局部估计对任意 $\epsilon_H > 0$ 给出那里的 $|H_{\eta,u}| \ll_{e,\epsilon_H} U^{\epsilon_H}$。于是

$$\sum_{u \in B} |L_S(w, \chi_\bullet(u)) H_{\eta,u}(s, w, z)| \ll_\eta U^{R(\delta) + \delta/2 + 12e + \epsilon_r + \epsilon_n + \epsilon_H} (1 + T_1)^{A'_\eta}.$$

这里 $A'_\eta$ 有限，并在最终外部尾项阶确定之前就已固定。

令 $\varepsilon_c = 12e + \epsilon_r + \epsilon_n + \epsilon_H$。缓冲倒数项的代价为对任意 $\varepsilon_d > 0$ 的 $U^{\varepsilon_d}$，而 $\zeta_{FS}(6z_0)$ 是绝对有界的。各测试函数在三个独立高度上的联合 $L^1$ 范数有界。
