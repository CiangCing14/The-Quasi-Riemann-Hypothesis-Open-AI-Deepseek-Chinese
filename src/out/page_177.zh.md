提取中的 $q^{d}it$ 在主项中于 $X/q^{d}$ 处抵消了 $q^{d}-it$。这证明了系数与 $X$ 和 $t$ 均无关。误差至多乘以因子个数 $\#\{d : d \mid R^{*}\} \ll_{\epsilon_1, B^{*}} Z^{\epsilon_1}$。系数本身也由多项式规模的 Euler 乘积估计给出 $Z^{\epsilon_1}$-界。这就证明了式 (18.45)。

对于式 (18.46)，对原和取绝对值。它在某个固定的正尺度以下为空；只要非空，固定圆环上的理想计数就给出 $O(X)$ 个点。这对 $t$ 和掩码是一致的。

式 (18.47) 中的带掩码和恰好等于

$$L_1(U_1, t)L_2(U_2, t) - L_1(V_1, t)L_2(V_2, t).$$

式 (18.45) 中的两个乘积主项均为 $c_{2\vartheta, R^{*}} T^{1+it} I_1(t) I_2(t)$。它们相互抵消。每个带一个误差的交叉项由 $Z^{\epsilon_1}(1+|t|)^{2J}$ 乘以 $U_1, U_2, V_1, V_2$ 之一所界，而误差之积在缩减辅助幂损失后具有相同的界。若四个尺度均至少为 $Z^{r}$，则每个至多为 $TZ^{-r}$，且因 $T \geq Z^{2r}$ 有 $1 \leq TZ^{-r}$。因此差为 $O(Z^{\epsilon_1}(1+|t|)^{2J} T Z^{-r})$。除以 $T^{1/2}$ 即证得式 (18.47)。当不存在非负下界长度时，式 (18.46) 将每个乘积界为 $O(T)$，从而给出最后一项断言。

将此引理应用于每个已分配的特殊子节点。关于其系数和公共掩码的假设由引理 18.2 得出；特别地，对于同一行、掩码和整乘积范数幂，主项在任何取绝对值之前就已抵消。初始时四个普通长度均至少为 $L$。在移除所选的 $t$-因子之前，$c_2$ 一侧的下界普通长度至少为 $L - c - w - c_2$，名义总长度为 $\alpha_1 = a_0 - c_2$：没有任何一个普通长度损失超过由两个真正公共支撑和放大器所提取的总量 $c + w + c_2$。另一侧对 $d_2$ 有类似的界。令

$$r = (L - c - w - \min(c_2, d_2))^{+},$$

并称具有此参考节省的一侧为第一侧，同时重新标记其相关的原始数据。若 $re_1 < r$，则每个所选普通长度满足 $a_{1,i} \leq re_1$，因此所有四个形式后普通尺度的对数长度至少为 $r - a_{1,i} \geq r - re_1 > 0$。在这些精确等积形式尺度上应用式 (18.47)。若 $re_1 \geq r$（包括相等），或者若 $r = 0$，则使用同一引理中的全尺度绝对体积回退。此分支中没有任何形式中心尺度被截断，形式差中仍保留一个恒为零的矩形。由此得到的节省为 $(r - er_1)^{+}$。结合另一侧的绝对体积，这给出了每个低端点除子二元组的聚合界，

$$\sum_{t,J} |c_{t,J}(h')| |P_{C,t,J}(h') P_{D,t,J}(h')| \ll Z^{a_0 - b_2 - r + 2\theta_N + \epsilon_1}. \tag{18.48}$$

此处及下文中，分离高度中的一个固定多项式是被默认理解的。为验证此界，原始系数和体积给出参考指数 $a_0 - b_2 + e_1 + e_2$ 和缩减 $-er_1 - re_2$，而除子计数给出 $t^{-}$。式 (18.34) 给出单行不等式

$$t^{-} - re_1 - re_2 - (r - re_1)^{+} = (t^{-} - re_2) - \max(r, re_1) \leq \omega_2 - r. \tag{18.49}$$

加上 $e_1 + e_2$ 后至多剩余 $e_1 + (e_2 + \omega_2) - r \leq 2\theta_N - r$。除子有界的分配只贡献 $\epsilon_1$，从而证明了式 (18.48)。这适用于人工项，即使商保留 $t$-素数，因为系数引理在每个矩形差内保持公共掩码、等积尺度和一个范数幂。
