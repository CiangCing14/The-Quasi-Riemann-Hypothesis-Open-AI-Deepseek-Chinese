族。第一个因子提供的族不必包含在 $\Theta$ 中；只是这样的选择只有有限多个。其余每个已展示的好素数因子都有其实际的局部六次指数，非平凡指数在该素数处分歧。

设 $v_1$ 为 $V$ 中所计等重数为 1 的素数的根长度，并令 $f = 2v_1$。在这样的素数处，行中固定因子 $G_c \operatorname{Vid}$ 的赋值为 2。该素数处不存在现有的移动特征，且 $\Theta$ 的每个特征在那里均非分歧。因此六次互反律表明，例外诱导要求

$$v_p(h') + 2 \equiv 0 \pmod{6}, \quad \text{即} \quad v_p(h') \equiv 4 \pmod{6}.$$

更一般地，在 $S$ 之外的每个素数处，例外诱导为 $v_p(h')$ 指定了模 6 的单个剩余类，由冻结的移动特征和 $G_c \operatorname{Vid}$ 决定。在其支撑之外，该剩余类为零。对于 $S$ 处有限多个选择以及单位和固定射线数据的每一种选择，$h'$ 的理想因此具有唯一形式

$$(h') = h_0 v_6,$$

其中 $h_0$ 固定且无六次幂因子。所展示的赋值 4 条件给出 $q_{h_0} \ge Z^{4v_1} = Z^{2f}$。在 $q_{h'} \ll Z^{m'_{\mathrm{act}}}$ 范围内的理想计数现在对每个非空范围给出更强的界 $O(Z^{(m'_{\mathrm{act}} - 2f)/6 + \epsilon_1})$，并采用通常的有界尺度约定。我们只用较弱的界

$$\#\{h' : q_{h'} \ll Z^{m'_{\mathrm{act}}},\ \text{例外}\} \ll Z^{(m'_{\mathrm{act}} - f)/6 + \epsilon_1} \le Z^{(m' - f)/6 + \delta_{fr,2}/6 + \epsilon_1}. \tag{18.41}$$

若该指数所描述的尺度低于 1，则被强制的理想 $h_0$ 使该范围为空，除非在同一有界尺度边界处。此论证包含主特征及 $\Theta$ 的每个其他成员。旧移动素数处的附加条件只会减少计数。它还覆盖了在正性之后划分标量有界时被允许的行。在单位素数处，这样增加的行可能是例外的，即使它不在原始划分中；这里不使用来自单位集 $t_2$ 的额外强制节省。

在例外行上，对每一对已分配的子节点取绝对乘积，并乘以式 (18.41)。设 $c_{t,J}(h')$ 表示其中心提取系数及有界提取标量。对于具有原始约化 $r_{e_1}, r_{e_2}$ 的分配，取绝对值后 $|c_{t,J}(h')| \ll_N Z^{-(e_{r_1} + e_{r_2})/2}$。使用绝对体积而非相消，在每一正形式尺度（包括子单位尺度）下，第 $j$ 侧未归一化的普通差为 $O(T_j')$，且未归一化的活跃槽贡献为 $O_N(\prod_{i \in I_j \setminus J_j} P_i)$。因此式 (18.35) 给出原始归一化体积

$$|P_{j,t,J}(h')| \ll_N N_{\mathrm{post},j}^{-1/2} T_j' \prod_{i \in I_j \setminus J_j} P_i = Z^{(\alpha_j - e_{r_j})/2 + e_j}$$

至固定半范数和高度因子，其中 $j$ 表示其 $C$ 侧或 $D$ 侧。于是，对一个已分配对和一个下端点数二进段（包括其计数）的指数为

$$a_0 - b_2 + e_1 + e_2 + t_- - r_{e_1} - r_{e_2} \le a_0 - b_2 + e_1 + (e_2 + \omega_2) \le a_0 - b_2 + 2\theta_N.$$

这里式 (18.34) 给出 $t_- - r_{e_2} \le \omega_2$，且 $r_{e_1} \ge 0$。因此

$$\sum_{t,J} |c_{t,J}(h')| |P_{C,t,J}(h') P_{D,t,J}(h')| \ll Z^{a_0 - b_2 + 2\theta_N + \epsilon_1}.$$

所展示的求和遍历一个固定的下端点数二进段；其分配已包含在 $\epsilon_1$ 中。它并不断言在 Möbius 分配之前存在独立乘积。从参考体积和名义例外计数中减去内部允许量，得到精确的代数恒等式

$$\frac{m' - f}{6} + a_0 - b_2 - (M' + \Delta_{\mathrm{child}}) = A - M - F_1 - \frac{5}{6} F_2, \tag{18.42}$$
