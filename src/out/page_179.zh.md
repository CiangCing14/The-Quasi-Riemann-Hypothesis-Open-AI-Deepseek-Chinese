这些解析分离不引入任何导数阶的 ξ 倍数。在一个固定的全乘积对数盒上，径向核为 $\Phi_{b_i}(R_{\mathrm{sc}} \exp(L(x)))$，其中 $L$ 是行对数范数与整列对数范数的一个固定线性形式。每个导数都是 $\Phi_{b_i}$ 的 Euler 导数的固定组合。引理 4.7 对所有这些导数关于所有 $R_{\mathrm{sc}} > 0$ 一致地给出界，具有任意指定的径向衰减与导数阶。人们不使用较弱的界 $R_{\mathrm{sc}}^J \le Z^{\xi}$（对 $R_{\mathrm{sc}} \le Z^a$）。在提取出其显示的中心幂之后，一个逆根在固定盒上为 $(q_u / Z)^{0-1/2}$；其导数只花费依赖于 $H_N$ 及其阶的固定常数。引理 4.5 使用完整的加权 Fourier 积分，而不是对 $Z^{\xi}$ 以下各高度的上确界。所需的阶数 $J$（可能依赖于 $N$）提升一个输入半范数阶与一个固定常数，而不是一个 $Z^{J\xi}$ 指数。反射同样作用在至多两个具有固定 gamma 形状的平面上；更大的导数阶提升有限的半范数阶与高度阶，而上环子份额 $\xi/2$ 保持固定。方程 (18.12) 中的固定多项式高度因子由这些加权 Fourier 测度以其所需的有限阶积分，而不改变先前选定的 $Z$ 的指数。

离散标签计数同样只被使用一次。在为共同支撑、除数或分配的一族提取出所示的指数之后，在应用分离元组半范数之前，将其绝对加权计数测度除以该总质量。这留下一个质量至多为 1 的测度；其已提取的指数不再在光滑范数中被计入。根据全乘积构造，每个 Fourier 测度对活跃标签是共同的。

指定槽计数之前的选择。按以下顺序选择参数。首先，由有界实范围与 $\epsilon$，选择 $\rho, \sigma, \delta > 0$，其中 $\delta$ 相对于 $\rho, \sigma$ 很小，使得
$$T_{\mathrm{term}} := \rho + \delta + \rho/6 + 3\sigma + 5\sigma/3 < \epsilon/4.$$
这界定一个终端宽度下限、对角或例外损失；所示的频率与数值支撑修正则属于每阶段的 $\xi$ 容许量。以如上所述的 $D$ 与 $C_* \ge 1$，仍然在指定 $N$ 或其固定剖面之前，选择
$$\xi < \min\left\{\frac{\delta}{2}, \frac{\rho}{30}, \frac{\sigma}{4C_*}, \frac{\epsilon}{16C_* D}\right\},$$
$$\eta < \min\left\{\frac{\sigma}{6}, \frac{\epsilon}{16C_* D}\right\}, \qquad \epsilon_0 < \frac{\epsilon}{16C_* D}. \tag{18.52}$$
这些选择使严格下降至少为 $\sigma/2$，保持比较裕量与填充核心，并且对 $\kappa \in [3/4, 1]$ 是一致的。

固定槽系统的选择。现在固定任意不依赖于 $Z$ 的 $N$、算术数据与剖面窗口。构成 $H_N$ 以及直至深度 $D$ 的有限全支撑盒。它们的固定因子 $\exp(O(H_N))$ 归入常数。在施加最终阈值 $\log Z \ge C H_N / \xi$、方程 (18.9) 中的阈值以及方程 (18.20) 之后，所有出现的列范数、根式范数与掩码范数都具有独立于移动标签的有界对数范围。在这些范围中，为每个任意小的幂估计选择局部份额，使得一个阶段内的份额总和至多为 $\epsilon_0$。这些份额可能依赖于 $N$。例如，掩码删除中的两个除数质量与至多 $N$ 个冻结槽质量可以各自使用份额 $\epsilon_0 / (10(N + 2))$。在素数估计中，主平方指数恰为 $\kappa z$，而围道位移代价为 $2ez$，总 $z$ 有界，而非 $N\eta$。为 $e$ 选择其指定的份额；固定的特征展开与 $\log Z$ 的幂在依赖于 $N$ 的阈值之后被吸收。当各个 $z_i$ 趋于零时同样的推理适用，因为 $P_i \ge 1$。对于除数分配，使用全局界 $\tau_{N+2}(v)^C \ll_{N,C,a} q_v^a$ 与 $C_N^{\omega(v)} \ll_{N,a} q_v^a$，其中 $a > 0$ 充分小，而不是在每个素数处的固定损失。Rankin 的固定根式界以相同的局部份额处理。唯一一个归一化池平均值在一个阶段中只有其单一密度损失。
