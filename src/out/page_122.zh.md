这里 $F$ 是实长度之和 $N + V$，因此在起始节点处 $F = F_0$。在一个余量为 $c_{\text{node}}$ 的节点处，两个假设恰好是

$$F - M - Q - z_0 \geq c_{\text{node}}, \qquad 4F - 3M - 6z_0 \geq c_{\text{node}}. \tag{17.9}$$

特别地，$M + z_0 + c_{\text{node}} \leq F$。数 $Q$ 是已经固定的穿刺根式的实际对数范数，而非二进中心。参数 $M$ 是固定的对数列长度；第一个 Poisson 检验的尺度为 $Z^M$。

设 $M_{\max}$ 为起始行长度的上界。选取 $0 < d \leq c_* / 200$，并令

$$D = \left\lceil \frac{M_{\max} + 2}{d} \right\rceil + 1.$$

我们使用正参数 $\eta, \tau, \pi, \tau_{\text{ref}}, \pi_{\text{ref}}$，它们按证明末尾的量化顺序选取。这里 $\eta$ 是仅界定固定环形比值的对数的局部化容差，$\tau$ 是两个 Poisson 尾部比较中的公共容差，而 $\pi$ 界定总量自由选取的局部小幂损失。在深度 $h$ 处令

$$c_h = c_* - 7h\eta, \qquad c_{\text{node}} = c_h,$$

并施加行上限 $M \leq M_{\max} - hd$。我们通过对 $h \leq D$ 的反向归纳来证明该估计。以下每个保留下来的行参数都是非负的。我们将证明，一个非终端段落将其至少减少 $d$，在任一所需余量中至多损失 $7\eta$，并使能量指数至多增加 $40\eta + \tau + \pi$。不会有任何不变量从固定的 $F = N + V$ 转移到实际的列范数。

短完成。对方程 (14.2) 中的立方因子作 Möbius 反演，给出精确恒等式

$$Z^{-N/2} \sum_{\substack{n \\ s f}} a(n)\chi_n(k)\chi_n(f)^4 d(n)W(q_n / Z^N)$$
$$= \sum_h \frac{\mu(h)\bar{\alpha}(h)^3 \Psi_k(h)^3}{q_h^N} T_{d_h}(Z^N / q_h^3;\, k), \qquad d_h(A) = d(h^3 A). \tag{17.10}$$

为检验标记与归一化两者，展开右端并令 $c = hb$。因子 $V_*(y) = y^{1/2} W(y)$ 将绝对系数变为

$$Z^{-N/2} \bar{\alpha}(c)^3 \Psi_k(c)^3 q_c^{1/2} \sum_{h \mid c} \mu(h).$$

标记为 $d(nc^3)$，与除数 $h$ 无关。除数求和除非 $c = 1$ 否则为零，从而证明了该恒等式。此处用到了 $\Psi_k$ 的乘性，包括其穿刺。

使用一个固定的光滑二进划分，其理想中心非负，单位二进元的中心为零。假设 $V < d$，且 $h$-二进元的中心 $\ell_1$ 小于 $d$。冻结 $h$，将 $h$ 所整除的槽位分配给它，而将其余槽位保留在完成指标上。一个存活的槽位于是具有个体系数 $a_i(p) 1_{p \nmid h}$。由于 $h$ 固定，这是一个有界系数，与当前 $k$、$f$ 无关，位于同一名义环上并具有相同的容限。它不是无限制的原始系数；下面的递归分支通过子零点分别恢复其原始槽位列表。对一个活跃子集定义 $z_a$ 为其名义槽位长度之和。分配只会删除槽位，因此精确地有 $0 \leq z_a \leq z_0$；实际元组范数 $\sum_\ell q_\ell^{-1}$ 从不被用作此容限。在联合 $(f, k)$ Hilbert 空间中的三角不等式使用 $q_h \asymp Z^{-1} h \ll 1$（对固定环而言），除分配给各子集时单独选取的除数损失外。有界因子 $\Psi_k(h)^3$ 是该空间中的一个压缩。
