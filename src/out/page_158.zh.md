正槽位，将已完成的零槽位估计与式 (18.12) 结合。在式 (18.3) 的区域内，$A \ge z$，因此

$$z \le \frac{M}{6\kappa} \le \frac{2M}{9}, \qquad \kappa z \le \frac{M}{6}. \tag{18.13}$$

于是正槽位的额外终端指数至多为 $\rho/6$。通过选取 $\rho, \delta$ 足够小，这些终端指数可以小于预留的最终损失。

对于高于下限的宽度，下面的双变换估计将首先证明非中心范围 $A \le 5M/6$。我们现在解释为何其余输入可以与该范围相比较。令

$$L = M/4. \tag{18.14}$$

对于 $A > 5M/6$，比较长度 $L$、$A - z - L$ 均至少为 $L$。在正槽位情形中，$(6\kappa - 1)z \le M - A < M/6$，且 $6\kappa - 1 \ge 7/2$；因此 $z < M/21 < M/20$。这也表明 $A - z > 2L$。

若一个原始平凡长度 $b < L$，则反射另一个因子。若两者均至少为 $L$，则引入长度为 $L$、$A - z - L$ 且具有相同两个剖面的比较；在单独估计该比较时仅反射其较长的因子。在两种情形中，该反射之后的总长度至多为

$$b + \{M - (A - z - b)\} + z + \xi \le 3M/2 - A + 2z + \xi,$$

其中 $b \le L$。式 (18.9) 将截断的反射尺度与配对的未反射盒乘子包含在同一 $\xi$ 中；被丢弃的尾部具有所述固定阶的界。因此

$$A_{\mathrm{comp}} \le 3M/2 - A + 2z + \xi. \tag{18.15}$$

对于 $z = 0$，这给出 $5M/6 - A_{\mathrm{comp}} \ge M/6 - \xi$。对于 $z > 0$，利用 $(6\kappa - 1)z \le M - A$、$A > 5M/6$ 以及 $z < M/20$ 得到

$$A_{\mathrm{comp}} \le \frac{23}{30}M + \xi, \tag{18.16}$$
$$A_{\mathrm{comp}} + (6\kappa - 1)z \le \frac{5}{2}M - 2A + 2z + \xi \le \frac{14}{15}M + \xi.$$

每个所需边界在 $\xi$ 项之前至少有 $M/15$ 的余量。选取 $\xi \le \rho/30$。在式 (18.9) 中的阈值之后，单位盒乘子已包含在 $\xi$ 中，因此每个保留的反射比较都在此相同宽度下调用先前已证明的非中心断言。这也完成了因子短于 $L$ 的原始情形。

在剩余情形中，令 $X_i = Z^{n_i}$，$Y_1 = Z^L$，$Y_2 = X_1 X_2 / Y_1$。则 $X_1 X_2 = Y_1 Y_2$，且所有四个平凡长度均至少为 $L$。从原始乘积中减去未反射的比较，留下槽位的公共乘积 $Q$；称结果为 $\Delta_k$。乘性及等积归一化给出显式公式

$$\Delta_k = \frac{Q}{\sqrt{X_1 X_2}} \sum_{l_1, l_2} \psi_k(l_1 l_2) \Big( W_1(ql_1/X_1) W_2(ql_2/X_2) - W_1(ql_1/Y_1) W_2(ql_2/Y_2) \Big).$$

该比较在原始允许行上有界。整个 $\Delta_k$ 的平方范数非负，因此可以放大到光滑行球内的所有行。在非中心情形中，改为放大原始乘积的平方范数。因此，下面的 Poisson 变换永远不会作用于选取例外行或非例外行的指示函数。
