仅在保留下来的轮廓上，命题16.1给出方程(16.10)中的分解。
对于 $I \subseteq \{1, \ldots, K\}$，其求和项为
$$
H^{(I)}_{\eta,u,Z} = H_{\eta,u}(s, w, z) \prod_{i \in I} D_i(u) \prod_{i \notin I} Q_i(u; z).
$$
所需的反射本原分子界由分子表示及其共轭的缓冲估计，连同引理4.10推出，正如命题16.1之前所验证的那样。保留下来的 $w$ 高度位于其允许集合中。每个保留下来的分子都是非主特征。
固定一个保留元组上的一个振幅集。对于主槽，$Q_i = -P_i^{z-1/2} Q_i$ 且 $|Q_i| \leq P_i^{g_i + \vartheta}$。对误差槽赋值 $g_i = 0$。方程(16.9)将 $I$ 中所有误差槽与分子联合起来加以界定；其证明同时对方程(16.11)中实际导子亏损用于不同的严格分歧标号。这不是对每个槽的单独分子容许量。由于 $H_{\eta,u} \ll_\epsilon U^\epsilon$，将这些估计相乘，并在选取预备幂次之后得到
$$
L_S(w, \chi_\bullet(u)) H^{(I)}_{\eta,u,Z}(s, w, z) \ll U^{\delta/2 + O(e) + \epsilon} (1 + T_1)^{A_1} \cdot Z^{\ell(17/50 - 1/2) + q_\ell + O(e + \vartheta + \epsilon)} P .
$$
这里 $A_1 < \infty$ 是目标与槽系统的一个固定高度阶，且 $\sum_i \ell_i g_i = q_\ell$，包括为误差所赋的零。没有使用误差槽的下界。
乘以假设的基数即证明了方程(10.13)在 $g = q_\ell$ 时成立，其中取 $\varepsilon_c$ 为 $e + \vartheta + \epsilon$ 的一个固定充分大的倍数。这个倍数仅依赖于固定的槽系统和有界实范围。有 $2^K$ 个误差子集。振幅向量的数目是固定的，而见证二进选择的贡献仅为 $1 + \log Z$ 的一个固定幂。因此所需的逐点重数界成立。这些集合仅在引理10.4使用 $H$ 移动了原始动态箱求和之后才形成。它们不用于延拓，也不单独积分。
对 $\sigma_0 = 7/8$ 和 $g = q_\ell$ 应用引理10.4。其在方程(10.15)中的指数为
$$
a - \frac{7}{8} + h\left(\frac{17}{50} - \frac{1}{6}\right) - a l y - \frac{\ell}{2} + q_\ell + d\left(R + \frac{\delta}{2} - \frac{17}{50}\right).
$$
由于 $-(1 - a)\ell - (\delta/2 - q)\ell = -\ell/2 + q\ell$，这正是方程(20.4)的第一行。代入几何量及 $a = (1 + \delta)/2$ 得到其第二行。特别地，$q_\ell = q/6$ 是一个以 $Z$ 为底的指数，而非 $dq/6$。方程(10.16)中的显式误差在有界 $d$ 范围上为 $O(e + \vartheta + \epsilon)$，这是在选取其余预备幂次之后。其上确界正是陈述中的那个。引理10.4还在 $N$ 之前固定尺度次数的情况下给出了所述的外部尾项。

底箱 $a = 51/100$ 有 $\delta_0 = 1/50$，且无需零见证。理想计数 $R = 1$，连同 $q \leq \delta_0/2$，给出

E(h) \leq C_0 + \frac{3}{4}\delta_0 = \frac{7}{1200} < 0. \qquad (20.5)
$$
其频率斜率 $R + \delta_0/2 - 17/50$ 为正，因此这界定了每个 $d \leq h$。略高于 $h$ 的小幅延拓将在下面加以控制。
