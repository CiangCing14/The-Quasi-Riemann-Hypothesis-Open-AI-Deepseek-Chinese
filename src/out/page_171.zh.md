定义 $PC,t,J (h')$ 和 $PD,t,J (h')$ 为其残差卷积乘以 $Npost,j$。相对于名义预归一化因子 $Z^{-\alpha_j/2}$，在忽略冻结槽振幅、保留的提取行标量以及已分离的外因子的情况下，第 $j$ 侧的精确提取系数为 $Z^{-erj/2}$。这些原始子项保留形式带号矩形，并非矩引理的调用；其形式对数长度可能为负。未发生截断。
    对于固定的 $N$，因子分配是除数有界的；其总和利用 $C_N \ll_{N,a} q^{ta}$（对任意固定 $a > 0$）有界，而非在每个素数处耗费固定指数。有界列范围内的 $O(\log Z)$ 个除数二进段使用其已有的对数份额。这些离散损失与数值 $\theta_N$ 项是分开的。
    为精确起见，提取 $Z^{g_2 - t_2}$ 后的另一个常见行标量为
$$vpart,\lambda (h') = \omega_\lambda (qGc Vid qh' / T_\lambda) 1part (h') \frac{F (D_2 , E_2 ; Gc Vid h')}{Z^{g_2 - t_2}} \zeta(h'), \quad |\zeta(h')| \leq 1,$$
其中 $\zeta$ 包含该二进段及这些 Fourier 参数的已分离行相位。它在保留划分和包围球之外为零，且 $|vpart,\lambda| \leq 1$。随后的估计逐二进段进行，然后与已允许的 $O(\log Z)$ 质量求和。根据诱导特征是否属于 $\Theta$ 来拆分已因子化的行和。对于 $\Theta$ 之外的行，Cauchy–Schwarz 给出两个非负子范数；对于 $\Theta$ 中的行，取逐点绝对乘积。仅在这些步骤中，才可将常见行权重、划分标量或提取行标量的绝对值以 1 为界，并将行扩大至公共 $m'act$ 球。这可能引入违反先前单位限制的额外例外行，但下面的仅特征计数已将其包含在内。两侧使用相同的合格类，并与方程 (18.33) 比较。
    首先考虑子诱导特征在 $\Theta$ 之外的行。两侧具有相同的合格条件，因为其特征相差 $\Theta$ 中的一个成员。在此类行上，首先用其两个矩形的范数之和来界定中心化子范数；对于非中心化子项，只有一个矩形。对于固定的侧 $j$ 和矩形 $\varrho$，将其前和后形式平坦尺度写为 $S_{\varrho,i}$ 和 $S'_{\varrho,i} = S_{\varrho,i} / q_{dj,i}$。在当前行、除数和活动标签之前，为每个当前平坦剖面类型选择一个固定的上支撑端点 $B_i$。仅当对某个 $i$ 有 $S'_{\varrho,i} B_i < 1$ 时才省略一个矩形；此时该平坦因子在每个非零整理想上为零。保留相等性以及所有其他剖面、掩码、行标量或算术零点。该检验独立于行和活动标签。
    对于保留的矩形，置 $x_i = \log_Z S_{\varrho,i}$ 和 $y_i = x_i - a_{j,i}$。固定端点检验和 $a_{j,i} \geq 0$，其中 $H_N$ 扩大以包含上端点对数的两个正部分，给出精确截断恒等式
$$\pi_{0,j,\varrho} = \sum_{i=1}^{2} (-x_i)_+, \quad \pi_{j,\varrho} = \sum_{i=1}^{2} (-y_i)_+, \quad 0 \leq \pi_{0,j,\varrho} \leq \pi_{j,\varrho} \leq \theta_N,$$
$$rclip,j,\varrho = \sum_{i \in J_j} z_i + \sum_{i=1}^{2} \left( (x_i)_+ - (y_i)_+ \right) = rej - (\pi_{j,\varrho} - \pi_{0,j,\varrho}) \geq 0,$$
$$Aclip,j,\varrho = \sum_{i=1}^{2} (y_i)_+ + \sum_{i \in I_j \setminus J_j} z_i = \alpha_j + e_j - rej + \pi_{j,\varrho}$$
$$= \alpha_j + e_j + \pi_{0,j,\varrho} - rclip,j,\varrho. \tag{18.36}$$
特别地，截断总和从其自身的预截断总和 $\alpha_j + e_j + \pi_{0,j,\varrho}$ 减少了 $rclip,j,\varrho$。不同矩形可以有不同的截断总和。保留的子单位尺度位于固定区间 $[1/B_i , 1]$ 内，因此其膨胀至尺度一保持有限半范数界。行特征、公共掩码和幸存槽权重不变。从预归一化因子 $Z^{-\alpha_j/2}$ 到该标准截断乘积的精确系数为
$$Z^{(Aclip,j,\varrho - \alpha_j)/2} = Z^{(-rclip,j,\varrho + e_j + \pi_{0,j,\varrho})/2}.$$
