式 (16.15) 给出
$$|H_{\eta,u,Z}(s, w, z)| \ll_\epsilon U^\epsilon \prod_i P_i^{17/50} = U^\epsilon Z^{17\ell/50},$$

对所有虚部一致成立。这就是式 (10.20)，其高度次数为零。它在各个局部因子的零点处仍然有效。引理 10.6 的数据已在上文验证，因此它适用于这些二元组中每一个物理行 $u \neq 1$。其分类包含非平凡的单位分子并允许主分母；这里没有使用检测器见证或选定的矩。
相对指数的 $d$-无关部分是
$$h\left(\frac{17}{50} - \frac{1}{6}\right) - \frac{l_y}{2} = -\frac{79}{800}. \tag{20.6}$$

式 (10.21) 中的行指数为 $63/50 < 2$。因此，式 (10.22) 中的小二元组和，相对于 $C(\beta_{*})$ 度量，其指数至多为
$$-\frac{79}{800} + 2d_{\min} + O(e + \epsilon) = -\frac{63}{800} + O(e + \epsilon).$$
在可调实损失取得足够小之后，它是负的。记 $m_{\text{small}} := 63/800$ 为这一固定的无误差节省。
对于大行，固定 $z_\infty > 2$。在 $(\Re s, \Re w, \Re z) = (2, 2, z_\infty)$ 上，同一式 (16.15) 给出
$$|H_{\eta,u,Z}(s, w, z)| \ll_\epsilon U^\epsilon Z^{\ell z_\infty}$$
对每个物理行和所有虚部成立。这验证了式 (10.23)。因此引理 10.6 给出，取 $B_0 = l_x /2 + 1 + l_y = 53/32$，

$$|R_\eta(U; Z)| \ll Z^{B_0 + h z_\infty + \epsilon} U^{1 + \epsilon - z_\infty},$$

并且，对每个固定的 $\zeta > 0$，在选取 $0 < \epsilon < z_\infty - 1$ 之后，
$$\sum_{U > Z^{h+\zeta}} |R_\eta(U; Z)| \ll Z^{B_0 + (h+\zeta)(1+\epsilon) - \zeta z_\infty + \epsilon}.$$

这里 $R_\eta$ 是引理 10.6 对当前物理表达式的行贡献。一个固定的足够大的 $z_\infty$ 可使最后的指数达到所需的负值。它是在 $\zeta$ 之后但在目标之前选定的。这些调用使用的是第 16 节中无商元组界，而非中心的主/误差分解。

20.4    端点不等式
我们接下来界定 $E(h)$，首先不计可调损失或高度因子。它们将按照定量的选择顺序恢复。回忆
$$\kappa = \frac{3}{4} + 2\Delta, \qquad \alpha = \frac{5}{6}.$$
在活跃的上端点 $\delta = \alpha$ 处，取命题 8.3 中的 $t = 3/2$。则 $r \geq 1 - O(\epsilon)$。在 $r = 1$ 两侧应用式 (19.3) 中的无槽放大估计。对于 $r \geq 1$，其指数为
$$1 - \alpha + (\alpha - \delta)r = 1 - \delta.$$
对于所述 $O(\epsilon)$ 邻域中的 $r < 1$，同一估计使用 $e(r) = 1$，因此其指数为 $1 - \delta r \leq 1 - \delta + O(\epsilon)$。固定的放大裕度与该邻域无关。
