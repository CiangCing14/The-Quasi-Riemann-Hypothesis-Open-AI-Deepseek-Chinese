由于 $v, \ell_b \ge 0$ 且 $T_0$ 有界，这也给出了每个保留对偶长度的界。对偶环带和 $k$ 的保留选择只有对数多个。选取一个非负的 $\epsilon_Z = O_{\mathrm{fixed}}(1/\log Z)$，大到足以覆盖方程 (5.37) 和 (5.38) 中的支撑偏移，并确保 $e \ge -\epsilon_Z$。

方程 (5.34) 中的指数满足
$$E_0 \le \max\{H,\, T_0 - S_0 - B_0\} + \epsilon_Z + \frac{5}{3}\tau_{\mathrm{ref}}.$$
为看出这一点，利用 $\max(H, v + \ell_b) - \ell_b = \max(H - \ell_b, v)$ 并丢弃非正的核项。第一支至多为 $H + 2\epsilon_Z/3$，因为 $\ell_b, S_0, B_0 \ge 0$。在第二支中，保留性给出 $v \le T_0 - 3\ell_b - e + \tau_{\mathrm{ref}}$，故它至多为 $T_0 - S_0 - B_0 + 5\epsilon_Z/3 + \tau_{\mathrm{ref}}$。此外，
$$T_0 - S_0 - B_0 = 2H + 2A_0 - N - N_0 - S_0 - 4B_0$$
$$\le 2M - O - N + O(\epsilon_Z),$$
由方程 (5.37) 和 (5.38) 得到。因此每个保留块，在其冻结的行部分固定后，其指数至多为
$$\max\{M - O,\, 2M - O - N\} + \tau_{\mathrm{ref}} + O(\epsilon_Z).$$

剩下的是计数冻结部分和有限展开。每个 powerful 理想唯一地写成 $x^2 y^3$ 且 $y$ 无平方因子：在一个素点上，$y$ 的指数是 powerful 指数的奇偶性，而一个奇的正指数至少为三。理想计数以及 $\sum_y q_y^{-3/2} < \infty$ 因此给出
$$\#\{m_{\mathrm{pow}} : q_{m_{\mathrm{pow}}} \ll Z^O\} \ll Z^{O/2}.$$

无平方因子的 $m_{\mathrm{sup}}$ 是 $S$ 的固定根式的一个因子，只有有限多个选择。$m_{\mathrm{pow}}$ 的好素点处的局部分支具有除子有界重数，其 Ramanujan 赋值也是如此。逐行的除子 Cauchy 以及随后对局部选择的求和只需 $Z$ 的任意小幂次。$h_0$、固定射线扇区和单位的选择是有限的，而实际的行和对偶环带只需 $\log Z$ 的幂次。这恰好将 powerful 贡献 $O/2$ 计算了一次。

在规定的 $\epsilon$ 容许范围内选取 $\tau_{\mathrm{ref}}$ 和局部小幂损失。然后提高 $Z$ 的固定数据阈值，使得 $O(\epsilon_Z)$ 项落在该容许范围内。块界、前面的计数以及已选取的尾部节省证明了方程 (5.36)。扭转断言由命题 5.1 中 $M_{A,J}$ 的范数扭转界推出。

为清楚说明在等长处所用的检验函数，令
$$V_G(y) = \frac{1}{2\sqrt{\pi}} \exp\left(-\frac{(\log y)^2}{4}\right).$$
它直接满足命题 5.1 的假设，具有 $\widehat{V}_G(t) = e^{t^2}$，并且对每个有限的 $A, J$ 都有有限的 $M_{A,J}$。因此前面的引理无需额外的环带扩张即可应用于它。在 $X = Z$ 处其精确的 Mellin 形式为
$$C_{V_G}(Z; m, \nu) = \frac{1}{2\pi i}\int_{(4)} Z^t e^{t^2} T(t + 1/2, \nu\chi_\bullet(m))\, dt.$$
在定义求和中，系数仍由 $q_c^{-1/2} q_n^{-1}$ 归一化；尺度出现在 $V_G(q_c q_n^3 / Z)$ 中。

最后取 $M = N = 1$。实际 $O$-二进段中的指数为 $1 - O/2 + \epsilon$。非负 $O$-二进段只有对数多个，其单位二进段也包括在内。将它们求和，并采用更小的预备损失，即得对每个容许的 $V$ 的等长结论：
$$\sum_{0 < q_m \le C_m Z} |C_V(Z; m, \nu)|^2 \ll Z^{1+\epsilon} M_{A,J}(V)^2. \tag{5.39}$$
