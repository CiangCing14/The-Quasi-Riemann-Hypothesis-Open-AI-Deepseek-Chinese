从基底 Z 过渡到基底 U 会把槽长从 ℓi 变为 ℓi /d ≤ 2ℓi，因此以这个二倍因子选出的一个网格在整个区间上满足矩要求。若
$$0 < \zeta < 5\ell - h = \frac{1}{48},$$
则对于 $h < d \leq h + \zeta$，供给量仍大于 $1/5$，其相对 $7/37$ 的余量为 $2/185$。
对于 $1/50 < \delta < \alpha$，使用理想行上指数 $R = R^* + \Delta/4$。对于 $\delta = \alpha$，使用 $R = 1 - \delta$。
两者都不小于 $1 - \delta$，所以
$$R + \delta/2 - \frac{17}{50} \geq \frac{33}{50} - \frac{\delta}{2} \geq \frac{4}{25} > 0.$$
下界也有正斜率。因此 $d = h$ 对 $d \leq h$ 界定了所有这些指数。扩展到 $h + \zeta$ 的代价至多为 $2\zeta$：事实上
$$R^* \leq 1 - \delta + \frac{\alpha - \delta}{2} \leq \frac{17}{12}, \qquad R^* + \Delta/4 \leq \frac{139}{96},$$
且 $139/96 + 1/2 - 17/50 < 2$。在 $\delta = \alpha$ 处以及下界情形的斜率都小于二。
对于 $d_{\min} \leq d \leq 1/2$ 且 $\delta \leq \alpha$，取 $t = 1$ 且不使用被选素数。命题 19.2 给出下界之外的理想指数 $1 - 2\delta/3$。使用稍大的公共指数
$$R = \frac{76}{75} - \frac{2}{3}\delta.$$
在 $\delta = 1/50$ 处它等于一，因此也覆盖下界。其斜率在该范围内为 $101/150 - \delta/6 > 0$。
在方程 (20.4) 中使用 $q \leq \delta/2$ 得到
$$E(d) \leq E(1/2) + O(\epsilon) \leq -\frac{529}{2400} + \frac{25}{96}\delta + O(\epsilon) \leq -\frac{49}{14400} + O(\epsilon) < 0. \qquad (20.11)$$
中间表达式由代入 $d = 1/2$、$R = 76/75 - 2\delta/3$ 和 $q = \delta/2$ 得到；最后一个不等式用了 $\delta \leq 5/6$。在 $\delta = \alpha$ 处，方程 (20.7) 中所用的计数及其正斜率已经控制了所有 $d \leq h$。连同第 20.3 节，这些情形覆盖了每一个物理行范数。只有 $d \geq 1/2$ 在行矩中使用了被选的物理素因子；在所有范围内每个物理槽都保持在高端修正中。
为了与 $C(\beta_{*})$ 比较，从每个理想指数中减去 $C(\beta_{*}) - C(7/8) = \Delta$。在自适应范围内这恰好是方程 (20.10) 中的比较；其唯一正的容量容许量为 $h\Delta/4$。其他端点范围在减去 $\Delta$ 之前的理想指数非正。因此它们全都保留与目标无关的主要高端余量
$$m_{\mathrm{hi}} := 1 - \frac{h}{4}\Delta = \frac{51}{64}\Delta.$$
低端指数的余量为 $m_{\mathrm{lo}} := \Delta$。主围道余量与逼近余量已在第 20.1 节建立；现在我们把所有损失一起选取。
