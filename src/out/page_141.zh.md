参数 $\pi$ 具有独立量词。设 $J_{\mathrm{step}}$ 为一个固定双 Poisson、双 Cauchy 分解树中自由除子或筛指数的使用次数与对数二进计数因子的最大数目，并在至多固定槽位上界的有限多种赋值中取最大。一旦 $L_{\mathrm{pow}}$ 界定了此类使用中每个尺度乘积的对数长度，就选取每个自由输入指数至多 $\pi/(2J_{\mathrm{step}}\max(1,L_{\mathrm{pow}}))$。对于充分大的 $Z$，至多 $J_{\mathrm{step}}$ 个对数因子的乘积至多 $Z^{\pi/2}$。这些选取使所有非中心、非频率的局部损失至多 $CZ^{\pi}$。它们包含保留的公共频率二进元和重构除子界。特别地，不同的分配 $\pi_{\beta}$、$\pi_{\mathrm{old}}$、$\pi_{\mathrm{count}}$、$\pi_{\mathrm{fib}}$ 以及有限并二进分配都是这一单一聚合量的一部分，而不是重复的 $\pi$ 大小的配额。固定射线和与固定半范数常数为常数。同样的约定定义了聚合终端损失 $\pi_{\mathrm{ref}}$。特别地，$\pi$ 不隐藏 $\eta$ 或 $\tau$ 的任何倍数。

这证明了条件归约估计 (17.17)，包括一旦作出下面的选取后的公共测度与有限阶一致性。剩下的是统一地固定这些选取，并通过有限深度应用归约。

选取顺序与终止。对于所要求的典范指数 $\epsilon_{c}=\epsilon$，首先像证明开始时那样固定起始范围、检验、槽位上界、$c_{*}$，然后固定 $d$、$D$。选取

$$\eta \leq \min\{d/16,\ c_{*}/(14D),\ \epsilon_{c}/(160D),\ c_{*}/1000,\ 1/100\}, \tag{17.66}$$

$$\tau \leq \min\{\epsilon_{c}/(4D),\ c_{*}/1000,\ 1/100\},\quad \pi \leq \epsilon_{c}/(4D),\quad \tau_{\mathrm{ref}},\ \pi_{\mathrm{ref}} \leq c_{*}/1000.$$

在两次 Poisson 比较中使用同一个 $\tau$。此时 $\pi$ 是一个目标聚合损失；其附属输入指数只有在有界尺度范围已知后才选取。

通过深度 $D$ 选取各个截断，包括每个完整更大或新鲜支集以及上述有界裁剪族，并构造 $I_{D}$、$L_{\mathrm{win}}$。包括活跃槽位的乘积区间以及终端常数 $C_{\mathrm{res}}$、$C_{\mathrm{width}}$、$C_{\mathrm{ker}}$，在深度范围内取最大。这是有限的，因为每段有有限多种分解类型且只有有限多段。令

$$F_{\max} = N_{\max} + V_{\max} + 11D\eta,\quad L_{\mathrm{all}} = 100(1 + M_{\max} + F_{\max} + z_{0,\max} + c_{*}).$$

这些界定了所有保留的尺度长度。确实，方程 (17.52) 及其后的界给出 $M \leq M_{\max}$ 以及 $N, V \leq F_{\max}$。非空列窗口有 $r \geq -\eta$，故 $\ell \leq (F_{\max} + \eta)/3$。所展示的父乘积将每个提取的除子长度界定为 $2F_{\max} + 6\eta$。例如 $d_{k} \mid C\,\mathrm{rad}(b_{1}b_{2})$ 给出 $\delta \leq r+2\ell+4\eta$，然后方程 (17.26) 给出 $H_{\mathrm{use}} \leq 7F_{\max} +18\eta+\tau$。终端活跃导子支撑在行、$f$、穿孔以及槽位上；它们的总长度至多 $M_{\max} + 2F_{\max} + z_{0,\max}$ 加上已展示的比率配额。方程 (17.11) 和 (14.11) 将保留的终端对偶长度界定为 $4M_{\max} +4F_{\max} +2z_{0,\max} +3d+12\eta +\tau_{\mathrm{ref}}$。在 (17.66) 之下，所有这些界以及精确的导子乘积长度都低于 $L_{\mathrm{all}}$。我们现在可以取 $L_{\mathrm{pow}} = L_{\mathrm{all}}$ 并选取实现 $\pi$ 和 $\pi_{\mathrm{ref}}$ 的附属小指数。

定义 $B_{\mathrm{crude}}$ 为如下方式得到的最大指数：在任一原始 Poisson 展开中，包括两个列和，将每个有界非频率理想或元素和替换为其在长度 $L_{\mathrm{all}}$ 处的格计数，并将每个显式范数因子，包括 (17.21) 中的 $1 + a^{-1}$，替换为其绝对上界。同样将除子有界系数与标记替换为其平凡多项式范数界。仅排除频率核本身。这些展开包含固定有限多个因子，因此这定义了一个有限的统一数。

对于反射尾部，类似地用其有界行、局部和活跃乘积计数以及 $a = X/qc_{2}$ 时的 $1 + a^{-1}$ 定义 $B_{\mathrm{ref}}$。不要计入保留长度处被丢弃的对偶指标。相反，方程 (5.2) 在其支集上给出

$$\frac{|d(\mu)|}{\sqrt{q_{\mu}}} \leq 27q_{\lambda}^{-k/3}q_{n}^{-1/2}q_{b}^{-1} \leq 27q_{\lambda}^{4/3} \quad (k \geq -4).$$
