在对任意小幂次进行约化后，关于 $C_0$、$D_0$ 的求和收敛，且对于同一固定的 $B > 2$，$R$ 求和也收敛。这给出了项 $(Q/Y')Pa^{1/6} Z^\epsilon$。加上对角项与非例外项便证明了该命题。

15.3 下界的完成

前述两个估计现在适用于精确低分离中同一重标度被加项的两个因子。

命题 15.3（补偿低估计）。对于式 (12.5) 中的探针、式 (12.4) 中的几何，以及每个 $\epsilon > 0$，

$$|I_{\eta,\mathrm{modified}}(Z)| \ll Z^{l_x/2+b/12+\epsilon} = Z^{3/16+\epsilon}. \tag{15.6}$$

该指数与目标和槽网格无关；常数与下阈值可能依赖于固定的算术数据、槽系统和光滑检验。

证明。对于固定的重标度子集与元组，令 $Q = q_b^* X' Y'$。其分离由式 (6.2) 给出，其中涉及 $A_{m,\sigma,v}(Y')$ 与 $B_{m,\sigma}^J(Z)$。令 $r_J = q_{pJ}/Z^d$；固定的环形支集给出 $0 < c \le r_J \le C_J < \infty$，且对元组一致成立。确切地，

$$X' = Z^{l_x-d}/r_J, \quad Y' = Z^{l_y-d}/r_J,$$
$$Q = q_b^* Z^{M'}/r_J^2, \quad Pa = Y'^2/Q = q_b^{-1} Z^{1/8}.$$

特别地，当 $Z \ge q_b^8$ 时 $Pa \ge 1$。将允许的固定数据下阈值放大，使得对元组比值也一致地有 $Q, Y' \ge 1$；这是可能的，因为 $M' \ge 1/2$ 且 $l_y - d \ge 5/16$。剩下的长度不等式为

$$l_x - d \ge 3/16, \quad l_y - d \ge 5/16, \quad l_y - d - 11b/6 \ge 1/12.$$

最后一个给出

$$\frac{Y'}{Pa^{11/6}} = q_b^* r_J^{-1} Z^{l_y-d-11b/6} \gg_{\mathrm{fixed}} Z^{1/12},$$

从而 $Pa^{1/6}/Y' \ll Pa$。因此命题 15.2 给出

$$\sum_{q_m \ll Q} |A_{m,\sigma,v}(Y')|^2 \ll (1+|v|)^{JGr}(Q/Y')Pa^{1/6} Z^\epsilon. \tag{15.7}$$

对行和施用 Cauchy–Schwarz、引理 15.1，以及 $(1+|v|)^{JGr/2}|\widehat{W_{c_0}}(iv)|$ 的可积性，现在将该元组的未重标度分离界定为 $Z^\epsilon$ 乘以

$$Q^{-1/2}(Q/Y')Pa^{1/6}\bigl[Z^{M'}\bigr]^{1/2}\bigl[Z^{M'}\bigr]^{1/2} = Z^{1/12}/Y' Pa^{1/12} = r_J (X')^{1/2} Pa^{1/12}.$$

由于 $r_J$ 有界，这是 $O((X')^{1/2} Pa Z^\epsilon)$。

对于 $d = \sum_{i \in J} \ell_i$，重标度元组至多有 $Z^{d+\epsilon}$ 个，系数为 $O(Z^{-3d/2})$，且 $(X')^{1/2} \asymp X^{1/2} Z^{-d/2}$。因此总附加指数为

$$f(d) = d - 3d/2 - d/2 = -d \le 0. \tag{15.8}$$

选取各分量估计中的小幂次，使其和落在规定的 $\epsilon$ 之内。对有限多个子集求和便证明了式 (15.6)。对于式 (12.3) 中已定义的 $C = C_{II}$，主信号所用的归一化满足

$$C_{II}(s) = l_x/2 + s - 1 + h/6 = s - 11/16, \tag{15.9}$$
$$C_{II}(7/8) = 3/16 = l_x/2 + b/12.$$

因此，在第二部分所假设的矛盾之下，除去任意指定的 $\epsilon$ 外，该下界比 $Z^{C_{II}(\beta_{*})}$ 小恰好 $\Delta = \beta_{*}- 7/8$ 的幂次。
