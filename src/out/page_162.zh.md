乘积支撑约定给出 $q_a/(X/q_C), q_b/(X/q_D) \in \exp([-H_N, H_N])$，因此在外扇区中对 $T_1$ 取上确界时，式 (18.21) 中的自变量至少为 $q_h/(e^{2H_N} T_{\sec})$。将前述整二元组局部化应用于这个真正的互素桥。若 $K = \log_Z T_\lambda$ 是某个保留二元组的上长度，则

$$q_e = q + R + E, \quad K \leq K_0 + \delta_{fr,1}, \quad 0 \leq \delta_{fr,1} := \frac{\xi}{2} + \frac{\log(C_d C_{\sec})}{\log Z} < \xi. \tag{18.22}$$

上面已估计的零频率是原公共光滑行球的零项；它在截断行定义域上不会被恢复。后续账本保留可能的不等式 $K_0 - K \geq -\delta_{fr,1}$。

对每个保留二元组和每个真正的公共支撑分配，定义 $C_1(a, b; h)$ 为完整的桥求和项，它也定义在那些与 $CD$ 各自不交且被旧掩码允许的非互素剩余对上。使用固定的双特征 $R(a, b)$、完整的零延拓 $G(a, h)$、$G(b, -h)$、所展示的整积特征，以及相同的二元组权、核、逆根和形式乘积范数。CRT 仅在 $(a, b) = 1$ 时将此定义与真正的求和项等同。在每个有限列壳上，精确恒等式为

$$\sum_{(a,b)=1} C_1(a, b; h) = \sum_{a,b} C_1(a, b; h) \sum_{s \mid a,b} \mu(s).$$

完整的无平方因子 Möbius 和消去了人为的非互素对。在估计独立因子之前插入它，并令 $s_0 = \log_Z q_s$。在归一化行范数和两个整积范数中分离固定射线相位与所有光滑因子。在这些变量下，核为固定对数盒上的 $\widehat{\Phi}_1(R_{sc} x/(y_1 y_2))$。若其聚合尺度比 $R_{sc}$ 在扇区上变化，则将该单一归一化外比值作为另一个坐标纳入。截断在式 (18.19) 的公共乘积圆环上选取，先于固定活跃槽标签。因此一个傅里叶系数测度对行和所有活跃标签是公共的。它在每个整列上提供一个行相位和仅一个范数幂，连同冻结外范数中的相位。它在两个普通变量或两个矩形上不引入单独的幂。完整核与逆根保持到这一分离为止；在 $D_b$ 内取其绝对上确界将不保持该系数。仅在此分离之后对 $h$ 应用 Cauchy–Schwarz，并且仅在那之后使用 $|G_{\xi_r}| \leq 1$。$C$ 侧得到的正范数为

$$N_C = \sum_{h \neq 0} \omega_K(q_h/Z^K)^{-(A-c)/2} Z \left| \sum_{s \mid a} A_C(a) \tau'_C(a) q_a^{it} G(a, h) \right|^2, \quad \omega_K \geq 0,$$

并且存在类似的 $D$ 范数。这里 $\tau'_C$ 包含一个分离出的固定射线特征。$A_C$ 中的所有固定掩码仍然存在。因此完全提取与乘性使式 (18.18) 中的系数保留下来，现在乘以 $G(a, h)$。特别地，两个矩形保留相同的分配普通幂、特征、穿刺和范数幂。

这两个范数之外的因子具有指数 $m - A - R/2 - E$。公共支撑标签和 Möbius 标签的绝对数量具有指数 $p + s_0 + \epsilon_1$。为一致地证明公共支撑计数，先计数其根，得到 $O(Z^{p+\epsilon_1})$。对于多项式范数的固定根 $c$ 和任意固定 $T$，Rankin 界给出

$$\#\{v : \operatorname{rad}(v) \mid c, \ q_v \leq Z^T\} \leq Z^{aT} \prod_{\substack{r \mid c \\ r \text{ prime}}} (1 - q_r^{-a})^{-1} \ll Z^{aT + \epsilon_1}$$

对每个固定 $a > 0$ 成立。选择小的 $a$ 并使用多项式规模的 Euler 积估计。这将 $C, D$ 中幂的选择界定在任意小的幂内。它们的分配以及 $e$ 的选择具有除子有界重数。最后有 $O(Z^{s_0 + \epsilon_1})$ 个可能的 $s$。
