现在固定一个原始目标 $\eta$。选取其允许的固定算术数据以及最终排除集 $S$，包括其导子、共同截断，以及刚才描述的那些进一步的固定排除项。物理表达式、$H_\eta$、$c_S$ 以及信号都使用这同一套数据。群 $T$ 和槽位系统保持与目标无关。固定由前述结果为此数据提供的所有内部矩、半范数和 Sobolev 阶。它们关于移动模数、共同掩码和冻结标签的一致性给出了一个有限的 $A_\eta$，它支配所有保留的高因子的乘积，包括二进因子、素因子、分子反射因子和行计数高度因子。它独立于任何后续的外部检验阶。全高度修正界以及共享解析引理中的直接全局界或绝对界同样为所有被丢弃的物理片段给出了一个有限的尺度次数 $B_\eta$，独立于后续的阶 $N$。将这些片段归一化并对它们的有限多种类型求和，只会增大这个固定的 $B_\eta$。

我们使用在 19.2 节末尾验证的高度上界。设 $A_{\mathrm{ht},\eta} \le A_\eta$ 支配有限多个探测器高度阶，必要时增大 $A_\eta$，并令

$$\tau_{0,\eta} := \frac{d_{\min} \epsilon_{\mathrm{ht}}}{20(1 + A_{\mathrm{ht},\eta})} > 0.$$

这个数在目标的保留阶确定之后、但在 $N$ 和 $Z$ 之前固定。若 $0 < \tau \le \min\{d_{\min}/100, \tau_{0,\eta}\}$ 且 $T_1 = Z^\tau$，则对 $U \ge Z^{d_{\min}}$ 和充分大的 $Z$，

$$T_1 \le U^{1/100}, \quad (1 + T_1)^{A_{\mathrm{ht},\eta}} \le 2^{A_{\mathrm{ht},\eta}} Z^{d_{\min} \epsilon_{\mathrm{ht}}/20} \le U^{\epsilon_{\mathrm{ht}}/10}.$$

由 $\epsilon_{\mathrm{ht}}$ 的定义，这在整个适度范围内证明了引理 8.2 中每个字面条件 $(1 + T_1)^A A \le U^{\epsilon/10}$。第一个界也使探测器的粗略误差 $U^{-189/100+o(1)} T_1^2 \le U^{-187/100+o(1)}$ 趋于零。每个带缓冲的适度范围都有 $d \le h + \zeta < 1$；小行和绝对大行不使用带缓冲的截断。

外部坐标的固定有限列表，包括物理的 $\Im z$ 坐标，使用方程 (10.14) 中的单一分配。其矩阵由槽位系统和有限多个保留估计固定，并且独立于外部导数阶。对于每个这样的 $\tau$，二进估计、见证估计和素估计可以按其陈述所允许的那样，在 $\tau$ 之后选择其辅助外部阶，使得它们的完整逐点界成立。在吸收其被丢弃部分时选择一个严格的幂间隙；由此得到的外部半范数常数随后被依赖于 $\tau$ 的下阈值吸收。对于任何所要求的剩余阶 $N$，这些辅助阶可以进一步增大；这只会改变外部半范数常数和下阈值，而不会改变 $A_\eta$、$B_\eta$ 或 $\tau_{0,\eta}$。没有任何内部矩被重新应用于外部微分的剖面。

因此，结合引理 20.1、所有行范围以及主余项估计，对于每个固定的 $N$ 和在此上界范围内充分大的 $Z$，有

$$|J_{\mathrm{II},\eta}(Z) - f_{\mathrm{II},\eta}(Z)| \ll_{\eta,N} Z^{C(\beta_*) - m} (1 + T_1)^{A_\eta} + Z^{B_\eta} T_1^{-N}.$$

下阈值允许依赖于 $\tau, N, \eta$。这就是方程 (11.1)。其低假设是取 $\omega = \Delta/2$ 的方程 (20.2)，且这两个函数不包含 $T_1$。取 $\sigma_0 = 7/8$、$C = C_{\mathrm{II}}$、上述 $m$ 以及已验证的上界 $\tau_{0,\eta}$，应用引理 11.1。它选取 $\tau_\eta$，然后选取一个共同支配的外部阶 $N_\eta$，最后选取阈值。它以 $\sigma = m/2 > 0$ 给出所断言的高估计。$\omega$ 和 $\sigma$ 都在目标之前固定。

命题 20.3 和方程 (10.2) 以 $\sigma_0 = 7/8$、$J_\eta = J_{\mathrm{II},\eta}$ 和 $f_\eta = f_{\mathrm{II},\eta}$ 验证了命题 2.1 的假设。这与 $\beta_* > 7/8$ 矛盾；因此 $\beta_* \le 7/8$。取 $\sigma_0 = 7/8$ 的命题 11.3 将原始 Hecke 结论推广到所有有限阶 Hecke 和 Dirichlet $L$-函数，允许主极点，并证明了定理 1.1。
